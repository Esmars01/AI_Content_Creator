### Phase 14 — Hardening, operations and documentation (2026-10-06)

Phase 13 was intentionally skipped by the product owner (ADR 0050). Everything below was exercised in mock mode on one host without a GPU; no money was spent.

#### Added
- Observability (ADR 0060): API request metrics per route template and a server span per request; spans for build nodes; tracing configured in every service; `ce_db.ops_metrics` (QC verdicts by adapter × language, attempts by reason and error class, coverage outcomes, NOT_MEASURABLE by dimension, world QC, consistency, memory conflicts, spend, rendered minutes) set as `ce_ops_*` gauges by the scheduler leader; worker task and render-time metrics recorded.
- `infra/observability`: Prometheus (Compose and native), 15 alert rules with runbook links, Alertmanager, Loki, Tempo, OpenTelemetry collector, Grafana with five dashboards generated by `scripts/gen_dashboards.py`; the Compose `observability` profile (images pinned by digest); `make obs-up`, `make obs-native`, `make gen-dashboards`.
- Native mode: `scripts/dev_native.py`, `make dev-native` / `make dev-native-down`.
- `scripts/backup.py` (`make backup`): backup, restore and verify of Postgres and both buckets.
- `scripts/load_test_scheduler.py` (`make load-test`) and `docs/LOAD_TEST.md` with measured runs (`docs/load-test/`).
- `scripts/demo.py` (`make demo`): the product path through the HTTP API.
- Fair-share leasing: `placement.fair_share`, `placement.per_org_candidates`, migration 0005 (`ix_gpu_tasks_queued_by_org`).
- `render.true_peak_retry_bitrates_kbps`: the delivered file's true peak is measured and fixed after encoding.
- Docs: ARCHITECTURE, SETUP, DEVELOPMENT, TESTING, TROUBLESHOOTING, INTENT, POLICY_AND_COMPLIANCE, OPERATIONS, DEPLOYMENT, OBSERVABILITY, SECURITY, LOAD_TEST, DEMO; BEHAVIOR, CREATORS, WORLDS, CONSISTENCY, VOCABULARIES, INVARIANTS and GPU_VALIDATION reviewed against the code; ADR 0060; D141–D148.
- Tests: route permissions over every mutating route, observability as code (fresh dashboards, defined metrics, runbook links), ops metrics, fair share, true peak, consistency features from real output shapes, API metrics and spans, security headers, the gateway's client address.

#### Changed
- Metrics are served only on side ports (`METRICS_PORT`); the scheduler's `/metrics` route left the worker API.
- The web app sends security headers (CSP, frame denial, nosniff, referrer and permissions policies, COOP, HSTS behind `WEB_HSTS`).
- The web gateway forwards only the nearest `X-Forwarded-For` hop; Compose's API trusts forwarded headers from its network only.
- Leasing serves organizations fairly by default.

#### Fixed
- A delivered render could exceed the true-peak target: AAC encoding at 192 kbit/s raised a −2.5 dBTP mix to +1.0 dBTP and flagged the version `needs_review` (found by the demo).
- Creator consistency read keys no producer writes: emotional tendencies, camera motion, blink and smile rates and head motion were never measured or always zero.
- `docs/MODELS.md` was stale and three request bodies lacked OpenAPI examples (Phase 12 omissions found by the full suite).
- The model-registry OpenAPI examples read like real GPU results; stale "Phase 13" docstrings.
